# variants/app_2022/

**Legacy (2022), not tested, not linted, not maintained.** A self-contained workflow with its own `bin/qlearn.py` and `setup/` (builds a
case from an area-of-study GeoJSON in `input/`); run it from inside this folder. It is **not interchangeable** with `src/evacrl`: other
table widths and another state-matrix layout ([the two code stacks](../../docs/repository.md#two-code-stacks-not-interchangeable)).
For new work use `src/evacrl` and `python -m evacrl.casebuild`.

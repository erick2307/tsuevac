`pyproject.toml`). The licence file does not say "or any later version", so that is what is declared; widening it is the

**Data are not covered by that licence.** Each data set keeps the terms of its source. This page says, for every folder that holds
data, what the repository itself records about the source, and what it does not. *Not recorded* means exactly that: nothing in the
repository or in what its owner has stated says where the data came from or under what terms; it is not a statement that
there are no terms. Fill those rows in before the repository is shared beyond people who already know the data.

## Libraries

The package depends on NumPy, Matplotlib and OpenCV (`opencv-python`); the optional groups on SciPy, pandas, GeoPandas, Shapely,
OSMnx, NetworkX, rasterio, folium, contextily, seaborn and Jupyter. They are installed from PyPI, not copied here; their licences
are theirs.

## How to cite

The software: [`CITATION.cff`](../CITATION.cff). The data: the sources above. OpenStreetMap asks for "© OpenStreetMap
contributors" next to any map or figure drawn from it.
